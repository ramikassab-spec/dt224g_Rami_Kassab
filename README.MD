## Git‑frågor

### Vad är skillnaden mellan git add och git commit?
- git add lägger till ändringar i staging‑området.  
- git commit sparar ändringarna i Git‑historiken med ett commit‑meddelande.

### Varför använder man branches istället för att jobba direkt i main?
För att kunna göra ändringar och testa funktioner utan att påverka huvudkoden. Det gör arbetet säkrare och mer organiserat.

### Vad händer rent praktiskt när man gör en merge?
Ändringarna från en branch (t.ex. dev) slås ihop med en annan branch (t.ex. main). Git kombinerar filerna och skapar en sammanfogad historik.

### Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?
- Push till GitHub: skickar koden till ett Git‑repo.  
- Publicera på Netlify: gör webbplatsen tillgänglig online för besökare.
